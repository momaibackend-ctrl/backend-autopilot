# Product direction

Backend Autopilot is a universal control plane that converts structured product requirements into a verified backend implementation. Its durable value is the combination of portable provider adapters, project isolation, formal workflow gates, reproducible evidence, and an auditable security boundary—not a particular model or backend stack.

v0.2 should add sandboxed execution, pluggable internal LLM providers, verified GitHub/Supabase staging adapters, richer planner inputs, durable worker claims, OpenTelemetry, and immutable external artifact storage. Billing and multi-tenant SaaS are deliberately absent, while organization/provider boundaries remain extensible.
