# Product direction

Backend Autopilot is a universal control plane that converts structured product requirements into a verified backend implementation. Its durable value is the combination of portable provider adapters, project isolation, formal workflow gates, reproducible evidence, and an auditable security boundary—not a particular model or backend stack.

The next release should add OS/container sandboxed target-test execution, pluggable internal LLM providers, Neon/Cloudflare provisioning adapters, richer planner inputs, durable worker claims, OpenTelemetry, and immutable external artifact storage. Billing and multi-tenant SaaS are deliberately absent, while organization/provider boundaries remain extensible.
